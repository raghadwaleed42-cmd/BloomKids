# Bloom Kids

Bloom Kids هو مشروع تخرج لمنصة تعليمية تفاعلية موجهة للأطفال، تهدف إلى تنظيم رحلة التعلم ومساعدة الطفل على البدء من المستوى المناسب له، ثم التدرج في المواد والدروس والأنشطة بطريقة واضحة ومترابطة.

تركز النسخة الحالية من المشروع على تصميم وتنفيذ الواجهات الأمامية وتجربة المستخدم، مع توفير واجهات مختلفة للطفل وولي الأمر والمعلم ومدير النظام.

## فكرة المشروع

جاءت فكرة Bloom Kids من الحاجة إلى تجربة تعليمية تساعد الطفل على التعامل مع الفجوات التعليمية الناتجة عن انقطاع أو عدم انتظام المسار التعليمي، وتوفر له نقطة بداية واضحة ومسارًا تدريجيًا بدل الاعتماد على محتوى متفرق وغير مترابط.

تبدأ رحلة الطفل باختبار مبسط لتحديد المستوى، ثم ينتقل إلى مسار تعليمي منظم يحتوي على المواد والدروس والأنشطة، بالإضافة إلى متابعة التقدم والإنجازات.

كما يوفر المشروع واجهات لولي الأمر لمتابعة تقدم الطفل، وواجهات للمعلم لمتابعة الطلاب وإدارة المحتوى التعليمي، بالإضافة إلى لوحة خاصة بمدير النظام.

## المستخدمون الرئيسيون

- الطفل
- ولي الأمر
- المعلم
- مدير النظام

## المواد التعليمية

يتضمن النموذج الحالي ثلاث مواد تعليمية:

- اللغة العربية
- الرياضيات
- العلوم

وتحتوي رحلة كل مادة على صفحات للدروس والمحتوى والأنشطة التعليمية.

## الواجهات الرئيسية

### الصفحة الرئيسية

تعرض فكرة Bloom Kids وطريقة عمل المنصة وأهم المميزات، وتوفر مسارات الوصول إلى تسجيل الدخول وإنشاء الحساب.

### المصادقة

يتضمن المشروع واجهات تجريبية لـ:

- تسجيل الدخول
- إنشاء حساب جديد
- التحقق من الحساب
- نسيت كلمة المرور
- إرسال رابط الاستعادة
- إعادة تعيين كلمة المرور

### تجربة ولي الأمر

تشمل:

- لوحة تحكم ولي الأمر
- الملف الشخصي
- الإعدادات
- متابعة الطفل
- الوصول إلى المواد والتقدم والنتائج

### تجربة الطفل

تشمل:

- اختبار تحديد المستوى
- المسار التعليمي
- المواد الدراسية
- الدروس
- الأنشطة التعليمية
- التقدم والإنجازات
- الشارات والمستويات

### تجربة المعلم

تشمل:

- لوحة تحكم المعلم
- متابعة الطلاب
- إدارة المحتوى التعليمي
- إضافة درس
- إضافة نشاط
- إضافة اختبار
- معاينة المحتوى
- إعدادات المعلم

### واجهات مدير النظام

تشمل:

- لوحة تحكم مدير النظام
- الإعدادات العامة للمنصة

## التقنيات والأدوات المستخدمة

تم تنفيذ المشروع باستخدام:

- HTML5
- CSS3
- JavaScript
- Session Storage لبعض سيناريوهات المصادقة التجريبية
- Chart.js لعرض بعض الرسوم البيانية في لوحة المعلم
- Font Awesome وLucide للأيقونات
- PNG وJPG وSVG للصور والعناصر البصرية

## تنظيم المشروع

تم فصل ملفات المشروع حسب وظيفتها لتسهيل التعديل والصيانة:

```text
BloomKids/
│
├── css/        ملفات التنسيق
├── images/     الصور والشعارات والأيقونات
├── js/         ملفات JavaScript والتفاعلات
│
├── index.html
├── login.html
├── register.html
├── forgot-password.html
├── reset-password.html
├── level-test.html
├── child-profile.html
├── subjects.html
├── parent-dashboard.html
├── teacher-dashboard.html
├── admin-dashboard.html
│
└── صفحات الدروس والأنشطة والإعدادات وباقي واجهات المشروع
```

## تشغيل المشروع محليًا

يمكن تشغيل المشروع بفتح ملف `index.html` مباشرة في المتصفح، أو باستخدام Live Server داخل Visual Studio Code.

## ملاحظة حول النسخة الحالية

النسخة الحالية من Bloom Kids هي نموذج Front-End تفاعلي يعمل داخل المتصفح.

لا تعتمد هذه النسخة على Backend أو قاعدة بيانات حقيقية، كما أن عمليات تسجيل الدخول وحفظ البيانات وبعض التفاعلات تعمل بصورة تجريبية بهدف توضيح تجربة الاستخدام ومسارات المستخدمين داخل المنصة.
